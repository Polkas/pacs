# Get all matched CRAN servers to the local `OS`

CRAN servers matched to the local `OS`.

## Usage

``` r
match_flavors()
```

## Value

`character` vector matched server names.

## Note

The Internet connection is needed to use the function.

## Examples

``` r
if (FALSE) { # \dontrun{
pacs::match_flavors()
} # }
```
